火山引擎 · Agent Plan

使用火山方舟 Agent Plan 订阅套餐的专属 API Key 提供图片生成、视频生成、语音合成与语音识别。可用模型通过 Access Key 查询套餐模型列表获取。

凭据

API Key 用于调用模型；Access Key 仅用于查询套餐支持的模型列表。均支持 ${ENV_VAR} 引用环境变量。

Access Key 获取 火山引擎控制台「访问控制 → 密钥管理」，建议使用仅授予方舟只读权限的 IAM 用户密钥。
