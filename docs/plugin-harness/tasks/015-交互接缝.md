# T015 - 交互接缝（选择/填写）

## 目标

建立「agent 需要用户选择/填写」的统一契约与默认 UI：新增内置工具 `ask_user`，工具执行中经交互接缝挂起（choice 单选 / form 表单 / confirm 确认），用户响应后恢复执行；超时与取消 fail-closed。桌面端提供内联交互卡片，CLI 提供文本交互。

## 范围

- 契约：`crates/plugin/tiangong-plugin-runtime/src/interaction.rs`（InteractionRequest/InteractionResponse/InteractionKind）。
- Core：`ask_user` 内置工具（经审批同款挂起/恢复机制：`StreamEvent::InteractionNeeded` + `Command::Interaction` + 等待超时）。
- 桌面：respond_interaction 命令 + 前端内联交互卡片（choice 选项组 / form 简易字段渲染 / confirm）。
- CLI：InteractionNeeded 时 stdin 文本交互（choice 输入序号、form 逐字段输入）。

## 依赖

- 前置：T014（挂起/恢复与超时机制同款）。
- 后续：三方交互处理器（capabilities.interaction=true）在插件生态就绪后接入路由。

## 任务

- [ ] 契约类型与序列化（kind: choice/form/confirm；schema 为 JSON Schema 子集：string/number/boolean/select）。
- [ ] Core `ask_user` 工具：tool-spec（模型可调用）、执行时发 InteractionNeeded 并挂起、收到响应/超时/取消后产出工具结果。
- [ ] `Command::Interaction { interaction_id, result_json }`；agent_input 通道扩展。
- [ ] 桌面 `respond_interaction` 命令 + 前端交互卡片（三种 kind 渲染 + 超时倒计时占位）。
- [ ] CLI 文本交互。
- [ ] 测试：choice 响应恢复、超时 fail-closed、取消闭合、form 校验。

## 验收

- 模型调用 ask_user(choice) → 用户点选 → 工具结果携带所选值，轮次继续。
- 超时/取消按拒绝闭合，工具结果标注。
- CLI 可完成同款交互。

## 验证

- `cargo test -p tiangong-core`（新增交互用例）；`yarn --cwd frontend build`。
