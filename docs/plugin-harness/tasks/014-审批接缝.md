# T014 - 审批接缝

## 目标

把「操作审批」的契约与路由从 Core 硬编码中抽离为可插拔接缝：审批请求/响应有稳定契约（含风险等级与选项），Core 等待超时 fail-closed，支持会话级「始终允许」，默认审批 UI 保持并增强；三方处理器路由骨架就位（真实三方处理器待插件生态）。

## 范围

- 契约：`crates/plugin/tiangong-plugin-runtime/src/approval.rs`（ApprovalRequest/ApprovalResponse/ApprovalRisk/ApprovalOption + ApprovalRouter 骨架）。
- Core：`react/tools.rs` 审批等待加超时（默认拒绝）；会话级始终允许集合（审批通过时可选记录，后续同工具跳过审批）。
- 入口：`respond_approval` 命令与前端审批卡片增加「始终允许（本会话）」。

## 依赖

- 前置：T003（桥接 approval.* 命名空间已登记白名单）。
- 后续：T015（交互接缝复用同款挂起/恢复机制）。
- Non-goal：不重写 Core Agent Loop；风险分级的真实策略（tool-spec dangerous 元数据）在 WIT 元数据扩展时接入，本期 risk 以 standard 占位。

## 任务

- [ ] 契约与路由骨架：ApprovalRequest（request_id/plugin_id/tool_name/summary/arguments/risk/options）、ApprovalResponse（approved/rejected/always_allow/modified + reason）、ApprovalRouter（默认处理器 + register/lookup，卸载回滚）。
- [ ] Core 审批等待超时 fail-closed：等待审批超过时限按拒绝闭合，工具结果标注超时拒绝。
- [ ] 会话级始终允许：`Command::Approval` 携带 always_allow，Session 记录允许工具集合，后续同工具在 Supervised 下直接放行（审计仍记录）。
- [ ] `respond_approval` 增加 always_allow 参数；前端审批卡片增加第三按钮；CLI y/n 增加 a 选项。
- [ ] 单元/集成测试：超时拒绝、always-allow 放行与持久化恢复、路由注册回退。

## 验收

- Supervised 下工具审批等待超时后按拒绝闭合，轮次不卡死。
- 「始终允许」后同工具本会话内不再弹审批；重启会话后仍生效。
- 路由骨架 register → lookup 往返，未注册时回退默认处理器。

## 验证

- `cargo test -p tiangong-core -p tiangong-plugin-runtime`；`yarn --cwd frontend build`。
