# 15. 记忆深度整理工具（tiangong-memory-consolidator）

对长期积累的记忆库做一次全量「深刻整理」：合并高度一致的记忆、重新归纳分类、
重建关联链，并遗忘低质量记忆。

工具是**独立制品**，位于 `plugins/tiangong-plugin-memory/consolidator/`：只通过
`tiangong-memory` 的公开 API（`MemoryHandle`）读写记忆，不修改 Memory 插件本身
的任何代码；接入方式与 sidecar 通用模式一致（竞争 Leader，天工运行时以
Follower 经 IPC 转发），因此天工正在使用时也可以安全运行，记忆数据始终只有一份。

## 使用

只需要指定天工根目录，工具会自动识别 Memory 系统配置的模型
（LLM / Embedding / Rerank，读取 `<根目录>/data/memory/config.json` 与
`<根目录>/models.json`）：

```bash
cargo run -p tiangong-memory-consolidator -- --root ~/.tiangong
```

| 参数 | 说明 | 缺省 |
|---|---|---|
| `--root <目录>` | 天工根目录（存储根），也可用环境变量 `TIANGONG_STORAGE_ROOT` | `~/.tiangong` |
| `--threshold <0~1>` | 相似度阈值，越高越保守 | `0.90` |
| `--group-limit <n>` | 每组最多参与的相似记忆数 | `6` |
| `--candidate-limit <n>` | 每条记忆的相似候选检索数 | `12` |
| `--max-nodes <n>` | 单次最多处理多少条记忆，`0` 表示全部 | `0` |
| `--dry-run` | 试运行：只报告不落库 | 关 |
| `--keep-low-quality` | 保留低质量记忆，不执行遗忘 | 关 |

建议第一次先用 `--dry-run` 预览将要发生的合并与遗忘，确认后再正式执行。

## 整理逻辑

1. **获取所有记忆**：分页拉取全部活跃记忆（扫描上限 5000 条，超出时用
   `--max-nodes` 分批处理并在报告中给出剩余数量）。
2. **逐条向量检索**：
   - 配置了 Embedding 在线端点时，本地批量计算向量与余弦相似度；用字符二元组
     倒排索引做候选预过滤，避免全量两两比较；
   - 未配置（或只有内置本地模型）时，退化为「经 Memory 混合召回取候选 +
     字符二元组 Jaccard 判定」；
   - 相似度达到阈值的记忆构成一个「高度一致组」（大小受 `--group-limit` 限制）。
3. **LLM 归一与分类**：把一致组（含主记忆与现有关联链）交给 Memory 配置的
   LLM，产出合并后的标题/摘要/关键词/认知分类/重要性，并给出低质量遗忘清单
   与新的关联链；LLM 未配置、调用失败或输出不合法时，退化为规则整理
   （保留信息最完整的一条，其余归档，关联机械重指向）。
4. **关联链重建**：已归档记忆的关系被重指向主记忆（保留方向、类型与权重），
   组内互连关系随合并消失；LLM 规划的新关系只允许指向组内或原关联链上出现
   过的记忆，防止幻觉 ID 波及无关记忆。
5. **过滤已处理**：每处理完一条就把整组标记为已处理，后续节点跳过已处理的
   记忆，直到全部整理完成。
6. **低质量遗忘**：标题为空、摘要过短且重要性低、长期未用且重要性低的记忆
   会被归档（软删除，不再参与召回，但仍可在记忆页查看）。

## 安全边界

- 整理会修改记忆库，`--dry-run` 不改动任何数据；合并与遗忘都走 Memory 既有
  的归档语义，不会物理删除。
- 低质量判定刻意保守（多重条件同时满足才遗忘），避免误伤短但有用的记忆
  （如用户偏好）。
- LLM 输出做结构校验：`primary_id`、`forget_ids`、关联目标必须落在给定范围
  内，否则退化为规则整理。
- 与天工同时运行时本进程为 Follower，所有读写经 IPC 转发给 Leader；本进程
  竞争到 Leader 时（天工未运行）在整理结束后自动释放租约。

## 代码位置

- `plugins/tiangong-plugin-memory/consolidator/src/main.rs`：CLI 与模型自动识别。
- `plugins/tiangong-plugin-memory/consolidator/src/consolidation.rs`：整理引擎。
- `plugins/tiangong-plugin-memory/consolidator/tests/consolidation_integration.rs`：
  端到端测试（合并、关联重建、低质量遗忘、试运行、批次上限）。
